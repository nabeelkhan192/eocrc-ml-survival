# Data directory — READ BEFORE ADDING ANYTHING

## DUA compliance (non-negotiable)

Case-level SEER data may **never** be committed to this repository or shared
in any form. The `.gitignore` blocks `data/raw/` and `data/processed/`, but
the gitignore is a guardrail, not a guarantee — double-check `git status`
before every push. The signed SEER Research Data Use Agreement restricts use
and disclosure of the data and prohibits linking it with other databases.
This repo shares **code and instructions**, so that any researcher with
their own SEER account can regenerate the cohort exactly.

## How to regenerate the analysis extract (SEER*Stat)

1. **Get access** (free): seer.cancer.gov → Data & Software → Request Access
   → **SEER Research Data** tier (any valid email works; no eRA Commons
   needed). Install **SEER*Stat** (Windows application).
2. **Database:** choose the largest available Research Data incidence
   database covering diagnosis years 2010+ (e.g., *Incidence — SEER Research
   Data, 17 Registries, Nov 2024 Sub (2000–2022)* or the latest submission).
   Record the exact database name — it goes in the Methods section verbatim.
3. **Session type:** Case Listing.
4. **Selection statement** (adjust variable names to your submission's
   dictionary):
   - Site recode ICD-O-3/WHO 2008 = Colon and Rectum, **excluding appendix**
     (exclude Primary Site C18.1)
   - Behavior = malignant; Diagnostic Confirmation = microscopically confirmed
   - Type of Reporting Source ≠ autopsy only / death certificate only
   - Year of diagnosis 2010–2019
   - Age at diagnosis 18–84
   - Sequence number = 0 or 1 (first malignant primary)
5. **Table (output) variables** — include at minimum:
   Patient ID; Age recode with single ages and 85+; Sex; Race and origin
   recode; Year of diagnosis; Primary Site – labeled; Histologic Type
   ICD-O-3; Grade recode; Combined Summary Stage (2004+); tumor size
   (CS tumor size 2004–2015 and/or Tumor Size Summary 2016+); Regional nodes
   examined; Regional nodes positive; CEA Pretreatment Interpretation
   (2010+); RX Summ—Surg Prim Site; Radiation recode; Chemotherapy recode;
   Survival months; SEER cause-specific death classification; Vital status
   recode.
   *Optional biomarker extension (later diagnosis years only — expect heavy
   missingness):* MSI, KRAS, perineural invasion, tumor deposits.
6. **Execute**, then Matrix → Export → **CSV with labels** (not codes) →
   save as `data/raw/seer_crc_export.csv`.
7. Open the CSV, copy the exact column headers into `COLUMN_MAP` in
   `src/config.py`, then run `bash run_all.sh`.
8. On the first real-data run, read the value-standardization **audit
   output** from `src/01_build_cohort.py` carefully and extend the mapping
   rules for any labels it did not recognize.

## Notes and known SEER limitations (report these in the paper)

- Chemotherapy and radiation variables under-ascertain treatment
  ("no/unknown" are combined) — you acknowledged this when signing the
  Treatment Data Limitations statement. Do not use them for comparative
  treatment-effectiveness claims; they are prognostic covariates only.
- Tumor size and staging variable names/derivations changed across
  submissions (2004–2015 CS era vs 2016+ vs 2018+ SSDI era). Combined
  Summary Stage is the most year-stable staging variable; verify each
  variable's coverage years in the current SEER*Stat dictionary.
- No recurrence, comorbidity, performance status, or molecular data (beyond
  limited SSDIs) — state this in Limitations.
